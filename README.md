# Café Layers

**Café Layers** is a student-friendly café located near Buddha Institute of Dental Science, Patna. This project is a clean, mobile-friendly website designed to showcase the café's menu, allow customers to contact or order easily, and reflect the warm atmosphere of the place.

## Features

- Fully responsive design (mobile-friendly)
- Full digital menu with pricing
- Order and contact options via WhatsApp
- Simple and elegant layout using HTML & CSS
- Easy hosting on Netlify

## Website

[https://bespoke-cascaron-dcccc3.netlify.app/](https://bespoke-cascaron-dcccc3.netlify.app/)

## Menu Highlights

- Biryani starting at ₹99
- Burgers, sandwiches, pizza, fries, and desserts
- Beverages including shakes and cold coffee

## How to Use

You can clone this repository and deploy it using:
```
git clone https://github.com/yourusername/cafe-layers.git
```
Then host it with Netlify or any other static site hosting service.
